# OOP 10 - JavaScript Object-Oriented Programming Practice

This project is a small JavaScript learning exercise focused on Object-Oriented Programming (OOP) concepts. It demonstrates the core ideas behind OOP in JavaScript, including constructor functions, prototypes, ES6 classes, inheritance, getters/setters, static methods, and encapsulation.

## Project purpose

The code in `script.js` is written as a study and practice file to help understand how JavaScript supports object-oriented design. It includes commented examples and exercises that cover:

- Constructor functions
- Prototypes and prototype chains
- Class declarations and class expressions
- Inheritance with `extends`
- Getter and setter methods
- Static methods
- Private fields and encapsulation
- Object creation patterns

## Files

- `index.html` – Minimal page that loads the JavaScript file
- `script.js` – Main OOP examples and exercises
- `README.MD` – Project documentation

## How to run

Because this is a front-end JavaScript demo, there is no build step or dependency installation required.

1. Open `index.html` in a web browser, or
2. Serve the folder locally with a simple HTTP server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Notes

- The project is educational and intentionally contains commented-out sections to show different OOP patterns.
- It is designed for learning rather than production use.
- Most of the logic is in `script.js`, so it is best viewed there while studying the concepts.

## Learning Outcome

By working through this project, you will get a better understanding of how JavaScript uses prototypes and classes to create reusable, organized object models.
